## 🌟 About The Project
Yeh ek modern **Full-Stack Web Development Agency Platform** hai jisme clients live service pricing dekh sakte hain, lead form ke zariye apne project inquiry submit kar sakte hain, aur ek intelligent **Gemini AI Assistant** ke sath chat karke apni zaroorat ke mutabiq plan aur database leads ki jankari turant prapt kar sakte hain.

---

## ✨ Key Features

- **🤖 AI Chatbot Assistant:** Google Gemini (`gemini-3.8-flash`) aur MySQL database leads integration ke sath real-time conversational support.
- **⚡ Database Power:** MySQL Triggers (`format_lead_name`) aur Stored Procedures (`CALL get_all_leads()`) ka use karke high-performance data management.
- **💼 Dynamic Pricing & Booking:** Basic, Business, aur E-commerce packages ke liye interactive lead submission.
- **🎨 Modern UI/UX:** React, Vite, aur Tailwind CSS par bana hua fast aur responsive interface.

## ⚙️ Installation & Setup

Apne local system par is project ko chalane ke liye niche diye gaye steps follow karein:

### 1. Repository Clone Karein
```bash
git clone [https://github.com/MD-Hussain-Akhtar/agency-project.git](https://github.com/MD-Hussain-Akhtar/agency-project.git)
cd agency-project

cd backend
npm install
PORT=5000
DB_HOST=localhost
DB_USER=root
DB_PASS=your_mysql_password
DB_NAME=agency_db
GEMINI_API_KEY=your_gemini_api_key

node server.js


cd agency-project/frontend
npm install
npm run dev
